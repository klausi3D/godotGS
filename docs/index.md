godotGS is a Godot 4.5 fork with an in-tree Gaussian Splatting module for
importing, rendering, and tuning splat-based scenes in the editor and at
runtime. This landing page is rendered from `overrides/home.html`; start with
the [quick start](getting-started/quick-start.md) or the
[compatibility matrix](reference/compatibility-matrix.md).
