14// Codec-aware staged source for plain v3 + bit 7 worlds, whose chunks are runs of GSQ v1 pages
15// (BV-C5b; docs/architecture/adr-beyond-vram-worlds.md D-12 "Decode location", §3.1, §3.4 step 5).
16//
17// The world loader validates the page directory and hands it over; no page is read at load. A
18// capture runs on the caller's thread, which on the streaming route is an async pack worker
19// (StreamingUploadPipeline::build_pending_upload_from_pack_job): it reads every page the range
20// touches through its PayloadPageStore (positional reads on the reader pool), checks
21// each page against its directory entry and stored SHA-256, decodes it with a per-thread
22// gs_gsq::DecodeContext (one ZSTD_DCtx each, leased from a pool) and, when enabled, checks the
23// decoded digest. The pack worker then packs the result into the 176 B PackedGaussian, as for
24// any other source.
25//
26// Decoded digest (BV-K9c): a source checks it by default (set_verify_decoded_digest). The
27// streaming load turns it off (gaussian_splat_world_io.cpp, staged branch): measured on the
28// tier-A flythrough it was 68.5 % of the per-page decode span (run 42687229044). It is redundant
29// there for on-disk integrity: verify_page() checks the header and the stored SHA-256 over every
30// stored byte, the page must match its page-table entry, and zstd checks each frame's checksum.
31// The decoded digest only re-hashes the output of a deterministic decode of those verified bytes,
32// so on this path it can catch only a decoder defect, which the codec golden-digest doctests and
33// the resident load (load_resident(), which still checks it) cover. The stored-page verify is
34// never skipped. Whether the check ran is exported (decoded_digest_verified,
35// pages_decoded_digest_checked), so a zero digest_nsec reads as "skipped", not as "free".
36//
37// Failure is visible, never repaired or skipped: a capture that meets a short read, a digest or
38// table mismatch or a refused decode returns false (the streaming system counts it in
39// chunk_payload_read_failures and retries with backoff), increments page_failures and records
40// the gsq_* reason in last_failure_reason.
41//
42// Telemetry (release counters, get_decode_stats()): pages and splats decoded, decode time, and
43// where each page was decoded (worker thread or main thread), so a test or probe can assert that
44// the async path ran instead of a main-thread or resident fallback.
45//
46// Threading: configure() runs once before publication. Captures may run concurrently from any
47// thread. The store owns the reader service, completion routing, decoder pool and counters.
48// `state_mutex` serializes lazy store startup and the once-per-source failure log.
