4// HLOD bake (ADR docs/architecture/adr-hlod-streaming.md §6.1-§6.3, slice S1a): builds the
5// world-aligned octree over a world's splats, merges interior nodes bottom-up and lays the payload
6// out node-contiguous and importance-ordered. Pure CPU, host-testable; no Resource or GPU state.
7//
8// The lattice is the world frame's (origin O = (0, 0, 0) for a world without one, see
9// gaussian_splat_hlod_tree.h); the root is the smallest lattice cell holding every centre, or the
10// origin-centred cube when the content straddles a plane through O.

40// Chooses the root for centres within [p_min, p_max] on the lattice with origin p_origin (§6.1):

42// the origin-centred cube [O - 2^e, O + 2^e) (r_origin_centred = true, r_cell = (e, 0, 0, 0)).

47// Bakes p_input. Fails closed (returns false, r_error set) on empty input, non-finite splat
48// fields (position, scale, rotation, opacity, SH), a leaf size outside [1, 16384], a payload

50// served. r_code, when given, receives ERR_OUT_OF_MEMORY for the last and ERR_INVALID_DATA
51// otherwise. The interior merge's per-node allocations are probed too (the bound comment in
52// gaussian_splat_hlod_merge.h); the node-count-sized build stacks and the <= kMaxChildren child
53// spans are not.
