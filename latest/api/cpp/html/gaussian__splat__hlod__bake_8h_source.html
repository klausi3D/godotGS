4// HLOD bake (ADR docs/architecture/adr-hlod-streaming.md §6.1-§6.3, slices S1a/S1b): builds the
5// world-aligned octree over a world's splats, chooses merged/selected interior nodes bottom-up and lays the payload
6// out node-contiguous and importance-ordered. Pure CPU, host-testable; no Resource or GPU state.
7//
8// The lattice is the world frame's (origin O = (0, 0, 0) for a world without one, see
9// gaussian_splat_hlod_tree.h); the root is the smallest lattice cell holding every centre, or the
10// origin-centred cube when the content straddles a plane through O.

21// Test-only, explicit opt-in candidate capture (S1b matched-arm quality exporter, ADR §9 S1b).
22// At every interior node of a QUALITY_SELECTION bake the baker builds a MERGED (SAT) candidate and
23// a SELECTED (A-area) candidate of the same count and keeps one. With a capture attached, BOTH are
24// kept here, together with the winner flag, before either is discarded. Positions are node-relative
25// (the node's cell centre), exactly as the baker holds them. The existing payload types are reused;
26// no file format is added. The capture never changes the baked tree: it only copies/shares.
27struct CandidateCapture {
28 struct Node {
29 SplatList sat; // MERGED candidate (rule 1 `sat`), children = the baker's chosen child payloads
30 QualityPayload area; // SELECTED candidate (A-area leaf-prefix selection), same count as `sat`
31 bool use_merged = true; // true: the SAT candidate won (S1b choice)
32 bool captured = false;
33 };
34 // REQUIRED, nonzero: byte ceiling for everything the capture retains (both candidates of all
35 // interior nodes). Exceeding it fails the bake closed; nothing is truncated or dropped.
36 uint64_t max_bytes = 0;
37 LocalVector<Node> nodes; // indexed by tree node index; filled for interior nodes only
38 uint64_t captured_bytes = 0;
39 uint32_t captured_nodes = 0;
40};
41#endif

79// Chooses the root for centres within [p_min, p_max] on the lattice with origin p_origin (§6.1):
80// the smallest cell (e >= -16) holding them all, or, if they straddle a plane through the origin,
81// the origin-centred cube [O - 2^e, O + 2^e) (r_origin_centred = true, r_cell = (e, 0, 0, 0)).
82// Returns false when nothing up to 2^62 m covers them (non-finite or absurd input).

86// Bakes p_input. Fails closed (returns false, r_error set) on empty input, non-finite splat
87// fields (position, scale, rotation, opacity, SH), a leaf size outside [1, 16384], a payload
88// that would not fit the 32-bit index space, or a splat-count-sized allocation that cannot be
89// served. r_code, when given, receives ERR_OUT_OF_MEMORY for the last and ERR_INVALID_DATA
90// otherwise (numeric image-domain range failures retain their typed error). The interior merge's per-node allocations
91// are probed too (the bound comment in gaussian_splat_hlod_merge.h); the node-count-sized build stacks and the <=
92// kMaxChildren child spans are not.
93// Forced-root and offline MERGE_ONLY bakes leave r_result empty on any failure.
94// Offline MERGE_ONLY requires a successful OfflineJob::reserve() for this input
95// and the frozen default leaf/interior parameters; it retains bake rule 1.
96bool bake_world(const BakeInput &p_input, const BakeParams &p_params, BakeResult &r_result, String *r_error,
