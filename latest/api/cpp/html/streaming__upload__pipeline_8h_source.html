56 // #766 (extends #757): the atlas byte stride the async payload in `packed_data` is
57 // actually written at. build_pending_upload_from_pack_job() packs on a worker thread and
58 // ALWAYS emits the 128 B PackedGaussian layout (pack_gaussians_range + sizeof(PackedGaussian)
59 // sizing/offsets); the 80 B quantized layout only ships through the SYNC path. Because
60 // packing and staging are decoupled for async jobs (staged later in finalize_upload_job),
61 // the EFFECTIVE stride can flip 128->80 in between (a mixed-DC asset becomes DC-uniform ->
62 // _refresh_quantization_dc_compatibility). Recording the true pack-time stride HERE, at pack
63 // time, lets finalize_upload_job hand it to _stage_chunk_upload_retirement so the #757
64 // retirement guard compares the stride the payload was really written at (not the post-flip
65 // stage-time stride) and fail-closes symmetrically for the async path. 0 = not set by the
66 // async packer (staging then falls back to the effective stride, matching pre-#766).
