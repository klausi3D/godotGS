9// #610 S7: RendererLifecycleOwner owns the per-scenario shared
10// Ref<GaussianSplatRenderer> and the two lifecycle transitions that create
11// and release it -- lazy instantiation (memnew on first demand) and the
12// move-out that hands the last Ref to a caller's deferred-release path. It is
13// the boundary the renderer-Ref lifecycle presents to the rest of the
14// director: instance / sphere-effector / world-submission code sees only the
15// renderer's IDENTITY (ptr() / is_valid() / is_null()) or an opaque strong Ref
16// (ref()), never the owned field. Mirrors S3's InstanceStore / S4's
17// SphereEffectorStore / S5's SubmissionStore.
18//
19// Like those stores it takes NO lock of its own: every access happens under
20// the director's single world_mutex, preserving the one ThreadOwnedMutex
21// ownership record the renderer-contract-boundary guard depends on. It adds no
22// mutex and holds no back-pointer to the director.
23//
24// DELIBERATELY NOT MOVED HERE -- these stay on the director because they are
25// the #628 / #611 renderer-contract territory this slice must not perturb, not
26// renderer-Ref lifecycle:
27// * GPU BRING-UP. `_initialize_world_renderer` dispatches
28// GaussianSplatRenderer::initialize() across the blocking render-thread
29// boundary and is one of the functions
30// tests/ci/check_renderer_contract_boundary.py allowlists + instruments
31// (it must reach world_mutex ownership + _report_renderer_contract_lock_violation).
32// It stays on the director and reaches the renderer through ref().
33// * The three-phase submit protocol's PHASE-2 HELD REF. submit_world_submission
34// copies the strong Ref (ref()) to inflate the reference count to 2 across
35// the unlocked apply, then unref()s it and retries the prune (#611 PR B2).
36// That protocol -- the copy, the unref, the retry -- stays verbatim in the
37// director; this owner only vends the Ref it copies.
38// * The DEFERRED LAST-REF RELEASE ordering (#628). A pruned / torn-down
39// renderer's Ref is move()d out via release() into a caller-owned release
40// vector or a local declared BEFORE world_mutex, so ~GaussianSplatRenderer
41// (a p_allow_timeout=false blocking dispatch) runs only after the lock is
42// released. This owner never drops the last Ref itself; release() just
43// transfers ownership to the caller, whose declaration order the guard's
44// check_renderer_ref_released_under_lock still enforces.
