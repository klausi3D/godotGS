57 // Package F1 (editable regions, ADR 14.5): an edited snapshot is a NEW immutable snapshot derived from `base` by
58 // lod/hlod_edit.*; the base, the world and a V4 package it may read are never modified. Edited leaves keep their
59 // node slot (stable NodeKey) and carry their replacement payload in memory (`edited`), in the snapshot's own leaf
60 // convention (absolute float32 positions). Every ancestor of an edited leaf is STALE: its baked payload no longer
61 // represents its children, so the selector must never draw it or use it as a fallback until a rebake (package F2)
62 // replaces it. edit_revision is 0 for an unedited snapshot and rises by exactly one per accepted edit.
63 enum EditState : uint8_t { EDIT_CLEAN = 0, EDIT_LEAF = 1, EDIT_STALE = 2 };
