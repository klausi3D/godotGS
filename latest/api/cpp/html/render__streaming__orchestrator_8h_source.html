92 // Bijective projection from the FULL 64-bit submission ObjectID to a small,
93 // orchestrator-owned uint32 "streaming slot id". The GaussianStreamingSystem
94 // registry identity is uint32 (its _make_chunk_key packs (asset_id<<32)|chunk_id,
95 // so widening it is a GPU-coupled redesign). Calling the registry with
96 // static_cast<uint32_t>(object_id) would truncate the high 32 bits: two distinct
97 // ObjectIDs sharing their low 32 bits would alias to the same registry slot. We
98 // instead assign each distinct ObjectID its own sequential slot, which is
