int LODConfig::calculate_lod_level ( float  distance) const

Calculate LOD level using Octree-GS formula.

L = floor(min(max(log2(d_max/d), 0), K-1))

Parameters

Returns

◆ get_splat_skip_factor()

int LODConfig::get_splat_skip_factor ( int  lod_level) const

Get splat skip factor for a given LOD level.

LOD 0: render all splats (skip 1) LOD 1: render every 2nd splat (skip 2) LOD 2: render every 4th splat (skip 4) LOD N: render every 2^N splat

Parameters
lod_levelThe LOD level
Returns
Skip factor (1 = render all, 2 = skip half, etc.)
