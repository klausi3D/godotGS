30// #610 S5: SubmissionStore owns the world-submission record — the active
31// contract data a GaussianSplatWorld3D installs on a SharedWorld — together
32// with the PURE functions that build a contract from it. It is DATA + pure
33// construction ONLY.
34//
35// The three-phase submit protocol STAYS in the director: submit_world_submission
36// arbitrates under world_mutex, applies the blocking render-thread dispatch with
37// the lock RELEASED, then commits/re-validates under world_mutex, the whole
38// sequence serialized by world_submission_apply_mutex. That protocol, its
39// rollback ordering (queue_restore_first), its R1–R4 re-validation and the prune
40// retry are orchestration, not record state, so they are deliberately NOT here —
41// the store never dispatches, never locks and never decides.
42//
43// Like S3's InstanceStore it takes NO lock of its own: every access happens under
44// the director's single world_mutex, preserving the one ThreadOwnedMutex
45// ownership record the renderer-contract-boundary guard depends on.
46//
47// build_contract() is the pure contract construction: (renderer-state snapshot,
48// record) -> WorldSubmissionContract, with zero side effects. It is defined in
49// the .cpp so it keeps reaching the file-local dictionary/override helpers.
50class GaussianSplatSceneDirector::SubmissionStore {
51public:
52 using WorldSubmissionRecord = GaussianSplatSceneDirector::WorldSubmissionRecord;
53
54 // --- record queries ---
55 bool is_active() const { return record.active; }
56 ObjectID owner_id() const { return record.owner_id; }
57
58 // Read-only view for the protocol's re-validation / getter reads and for the
59 // pure helpers below. mutable_record() is for the protocol's in-place field
60 // writes (renderer_restore_state) and the wholesale commit assignment; the
61 // active-flag transitions those produce are byte-identical to the pre-S5
62 // direct-field writes.
63 const WorldSubmissionRecord &get_record() const { return record; }

65
66 // Clear the record back to the inactive default. Matches the prior
67 // `world_submission = SharedWorld::WorldSubmissionRecord()` idiom used by
68 // release, cross-scenario eviction and teardown.
69 void reset() { record = WorldSubmissionRecord(); }
70
71 // --- pure construction (no side effects, no dispatch, no lock) ---
72 // Populate r_record from a submission DTO (owner/data/payload/overrides…),
73 // resetting renderer_restore_state and marking the record active.
