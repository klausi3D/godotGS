3// GSQ v1 page codec core (BV-C1a; docs/architecture/adr-beyond-vram-worlds.md D-12).
4//
5// One page is one plain-v3 chunk or one V4 node payload. It is split into 4,096-splat
6// sub-blocks in the caller's order, so a prefix stays a valid sample and any range decodes
7// without touching the other sub-blocks. Each sub-block is one zstd frame of SoA byte planes.
8//
9// Page layout (little endian, 256 B of header in front of the frames):
10//
11// 0 u32 magic "GSQ1"
12// 4 u16 codec id (1)
13// 6 u8 stored SH degree (0..3)
14// 7 u8 flags (bit 0: 21-bit positions, bit 1: per-splat normals)
15// 8 u32 splat count (1..65536)
16// 12 u32 stored bytes, header included
17// 16 u8[3] SH bits per band, then u8 opacity bits
18// 20 u16 splats per sub-block (4096), u16 sub-block count
19// 24 u8[8] reserved, zero
20// 32 u8[32] SHA-256 of the stored bytes: [0, 32) then [64, stored bytes)
21// 64 u32[16] stored size of each zstd frame; unused entries are zero
22// 128 f32[6] position min xyz, max xyz
23// 152 i32[6] log2 scale min xyz, max xyz, Q16
24// 176 f32[6] DC min rgb, max rgb
25// 200 f32[3] largest SH magnitude per band
26// 212 f32[3] page normal (the value of every splat when bit 1 is clear)
27// 224 f32[5] page area, DC alpha, stroke age, brush axes
28// 244 u32[2] page painterly_meta, render_meta
29// 252 u32 reserved, zero
30//
31// Sub-block planes, in this order (n = splats in the sub-block; each plane is n bytes):
32//
33// position 2 or 3 planes per axis: zigzag delta of the page-relative integer, the first
34// splat of the sub-block against 0
35// scale x, y, z low bytes, then x | y << 2 | z << 4 of the 10-bit high bits
36// rotation a, b, c low bytes, then a | b << 2 | c << 4 | index << 6
37// opacity 2 planes
38// DC r, g, b low bytes, then r | g << 3 | b << 6 of the 11/11/10-bit high bits
39// SH one plane per coefficient, biased signed integer, zero is exact
40// normal 2 planes per axis, only with flag bit 1
41//
42// Determinism (risk K10): the module's GCC/Clang flags include -ffast-math, and a digest that
43// depends on a floating point result is exposed to that and to contraction. So no value that
44// reaches the page or a decoded float passes through floating point arithmetic: floats are
45// read and built by their bit patterns, and everything between is integer. This TU also builds
46// in its own environment, without the module's optimization flags (SCsub). The one floating
47// point call, the sqrt seed in the .cpp, is corrected in integers, so its result cannot vary.
48//
49// Refusals are explicit: a field the page cannot carry (a per-splat area, degree 4 SH) fails
50// with a gsq_* reason and is never dropped. Reasons are returned, not printed, so a corrupt
51// page on a worker thread costs one failed decode and no log flood.

104// In Vector3 units: 0 up to degree 1, then 5 for degree 2 and 12 for degree 3.
105constexpr uint32_t sh_high_order_for_degree(uint32_t p_degree) {
106 return p_degree < 2u ? 0u : (p_degree + 1u) * (p_degree + 1u) - 4u;
107}
