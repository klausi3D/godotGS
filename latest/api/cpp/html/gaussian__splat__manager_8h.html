Detailed Description

Global singleton manager for Gaussian Splatting resources and configuration.

The GaussianSplatManager coordinates engine-wide Gaussian Splatting state including GPU buffer registration, performance monitoring, sorting configuration, and RenderingDevice lifecycle management for multi-threaded rendering.
