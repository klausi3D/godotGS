Detailed Description

The engine-side scene lighting a raster pass consumes.

#851.

Gathered once per frame from RenderDataRD + LightStorage by the raster stage (renderer/render_pipeline_stages.cpp) and handed to every TileRenderParams producer, so the baseline and painterly producers light a frame from the same inputs. The defaults are the "no scene" answer (shadow pass with null render_data): no lights, clustering off, permissive mask.
