30 // Bump whenever importer behavior changes in a way that requires existing
31 // imported caches to be re-imported. Godot's resource scanner compares this
32 // against the value stored in each .ply.import file and re-runs import()
33 // when they differ, so users do NOT need to manually wipe .godot/imported/
34 // after a fix lands in the importer.
35 // v0 (implicit): pre-versioning baseline.
36 // v1: switch to versioned importer.
37 // v2: optional Packed*Array fields are now zero-initialized at import
38 // time (see gaussian_splat_asset.cpp::_ensure_buffer_sizes —
39 // resize_initialized() instead of resize() for POD vectors).
40 // Caches written by v0/v1 may contain 0xC0C0C0C0 poison and must
41 // be re-imported.
42 // v3: preview thumbnails now serialize as Image resources instead of
43 // ImageTexture to avoid threaded importer deadlocks under
44 // `--headless --import`.
45 // v4: PLY DC-encoding default flipped from `legacy_bias` (sigmoid
46 // compression `1.5*sigmoid(x) - 0.25`) to `linear_rgb` (canonical
47 // Inria `sh*C0 + 0.5`). Caches written by v1-v3 carry the wrong
48 // `dc_encoding` tag and must be reimported to render with full
49 // contrast / saturation.
50 // v5: SH bands 1-3 are now propagated into the asset. Caches written
51 // by v1-v4 carry only DC color; the renderer fell back to flat
52 // per-splat RGB and lost view-dependent specular / fresnel detail.
53 // v5 caches carry full per-splat sh_first_order / sh_high_order
54 // arrays sized splat_count * sh_terms * 3.
55 // v6: imported GaussianSplatAsset payloads are saved as binary .res
56 // instead of text .tres to avoid multi-hundred-MB text parsing during
57 // scene loads.
58 // v7: per-chunk streaming bake (start_idx/count/center/max_radius/bounds)
59 // now stored on the asset so GaussianStreamingSystem::register_asset
60 // can skip the per-splat center/bounds pass on scene load. Old
61 // caches without the bake fall through to the runtime compute path
62 // (no breakage), but reimporting recovers the ~7-9s startup win on
63 // multi-million-splat scenes.
64 // v8: PLY loader now decodes integer-typed vertex properties
65 // (char/uchar/short/ushort/int/uint and int8..uint32 aliases) to
66 // their real value instead of silently returning 0.0 (issue #465).
67 // An asset imported by v1-v7 from a PLY with integer-typed fields
68 // holds zeroed positions/opacity/scales in its .res and must be
69 // re-imported to recover correct data; bumping the format version
70 // makes Godot's scanner re-run import() automatically.
71 // COORDINATION: the accepted GS-PERF-PRUNE ADR also plans a 7->8
72 // bump. This safety fix lands first and takes v8, so the pruning
73 // slice must take v9 to avoid a format-version collision.
74 // v9: GS-PERF-PRUNE slice 2b (issue #456) wires opt-in importance pruning
75 // (processing/prune_ratio + processing/prune_importance_threshold) into
76 // the importer. Pruning changes the saved array LENGTHS and the baked
77 // streaming-chunk records, so an asset imported by v1-v8 whose .import
78 // enables a prune option holds the un-pruned arrays in its .res and must
79 // re-import; bumping the format version makes Godot's scanner re-run
80 // import() automatically. NOTE: the raw .gsplatcache (PLY_CACHE_VERSION)
81 // is deliberately NOT bumped -- pruning happens AFTER the raw decode, so
82 // the cached decode is unaffected (ADR "Two distinct caches"). Because
83 // pruning is opt-in and Ultra stays byte-identical, no shipped asset
84 // silently changes on the bump.
85 // v10: the PLY binary/ASCII parser now rejects vertex-element
86 // `property list` declarations (issue #511) and accounts for elements
87 // declared before `vertex` (issue #512) instead of silently loading a
88 // misaligned/mis-offset vertex block. An asset imported by v1-v9 from
89 // such a PLY holds garbage splats in its .res, so bumping the format
90 // version makes Godot's scanner re-run import() automatically (which
91 // now either decodes correctly or fails loudly). This pairs with the
92 // matching PLY_CACHE_VERSION 2->3 bump so the raw decode cache is also
93 // invalidated. (SPZ has its own loader and does not share this parse
94 // chain, so ResourceImporterSPZ::get_format_version() is unchanged.)
95 // v11: the importer now rejects PLY assets with a non-finite (NaN/Inf)
96 // position/scale/rotation/opacity in ANY splat (issue #518). An asset
97 // imported by v1-v10 from such a PLY holds poisoned splats in its .res,
98 // so bumping the format version makes Godot's scanner re-run import()
99 // automatically, which now fails loudly instead of shipping the NaN to
100 // the GPU. No PLY_CACHE_VERSION bump is needed: the raw/runtime path is
101 // validated on every load via GaussianSplatAsset::load_from_file(),
102 // independent of the decode cache.
103 virtual int get_format_version() const override { return 11; }
