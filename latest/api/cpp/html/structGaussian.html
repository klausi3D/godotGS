Detailed Description

GPU-aligned structure for efficient splat rendering.

This struct is designed for direct GPU upload with std430 layout compatibility. It packs all per-splat data needed by the tile-based rasterizer including position, orientation, spherical harmonics, and painterly extensions.

Note: Must remain 16-byte aligned (144 bytes total). Do not reorder fields
without updating the corresponding GLSL struct definition.
