Detailed Description

Shared ProjectSettings helper utilities for the Gaussian Splatting module.

This header provides canonical, type-safe accessors for reading Godot ProjectSettings values. It replaces the many per-file static copies of _get_bool_setting / _ps_get_uint / _ps_get_float that were duplicated across the module.

Usage: #include "core/gs_project_settings.h" bool val = gs::settings::get_bool(ps, "rendering/gaussian_splatting/debug/enable_all_debug", false);
