45 // Every non-COMPLETE/EMPTY status means "no complete cut": selected_count is 0 and callers must
46 // not publish an active (empty) cut. When the root alone fails admission, a bounded bootstrap
47 // (ADR section 14.2) looks for a complete visible child frontier that fits every cap; its failure
48 // is reported as exactly one of the BOOTSTRAP_* statuses:
49 // BOOTSTRAP_EXHAUSTED - the configured search-work bound ran out; says nothing about feasibility.
50 // BOOTSTRAP_ARITHMETIC - a non-finite or overflowing cap computation was met.
51 // BOOTSTRAP_MISSING_RESIDENCY - expansion needed a visible child that is not resident.
52 // BOOTSTRAP_INFEASIBLE - the deterministic search expanded every admissible node and no
53 // frontier fits (not a proof over all frontiers; see select()).
54 // Not named `Status`: X11/Xlib.h #defines Status, and this header reaches the X11 display server TU.
