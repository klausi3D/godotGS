21// #1088: the atlas is allocated in fixed-size PAGES, and every chunk owns one
22// contiguous run of pages sized to its own splat count. A chunk's "slot" id is the
23// first page of its run, so the GPU-side splat base is slot * page_splats and the
24// shaders (which index gaussians[atlas_base + i]) are unchanged. Before #1088 every
25// chunk took a fixed 65,536-splat slot regardless of its size.
26//
27// Placement is best-fit (smallest free run that fits, lowest address on a tie) and
28// freed runs coalesce with their neighbours immediately. There is no compaction: when
29// no run fits, admission evicts least-recently-used chunks until one does (bounded by
30// the per-frame eviction budget; see GaussianStreamingSystem::_evict_until_atlas_fit).
31class GaussianAtlasAllocator {
