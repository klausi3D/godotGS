146 // --- Single-source per-frame reset helpers (#528) --------------------------
147 // The renderer clears stale telemetry field-by-field at several render-path
148 // sites. Those hand-lists used to be duplicated inline (drift risk: a new
149 // metric added to the struct but missed at a site silently reports the
150 // previous route's value). Each helper below owns exactly one logical group of
151 // fields; every reset site composes the groups it needs, so a group's field
152 // membership is defined once. `tests/ci/check_metric_reset_parity.py` fails
153 // closed if any struct field is neither covered by a helper nor listed in the
154 // guard's explicit not-per-frame-reset allow-list, so a newly added metric can
155 // never silently escape a reset decision. Every value assigned here is the
156 // field's struct default, so the helpers preserve the byte-identical behavior
157 // of the inline lists they replace.
158 //
159 // These are deliberately *partial* resets, not a blanket `*this = {}`: the
160 // sites intentionally leave cumulative/lifetime counters (e.g.
161 // total_frames_rendered, raster_pipeline_reformats) and per-stage outputs
162 // untouched. A single whole-struct reset would corrupt those.
163
164 // Per-frame raster tile occupancy + feature-flag snapshot.
165 void reset_raster_frame_stats();
166 // "Core" GPU tile pass timings (frame + overlap-count..raster).
167 void reset_gpu_core_pass_timings();
168 // Extended GPU tile pass timings (prefix, prefix CPU-sync fallback, resolve).
169 void reset_gpu_extended_pass_timings();
170 // GPU timeline / frame-pacing counters.
171 void reset_gpu_timeline_metrics();
172 // GPU readback-derived state cleared when no rasterizer is present:
173 // utilization, timing serial/behind, and the tile-sort sync fallback counter.
174 void reset_gpu_readback_state();
