Detailed Description

Per-chunk quantized Gaussian for maximum compression (Unity technique).

Uses per-chunk min/max bounds to normalize positions and scales, achieving up to 4x compression ratio with minimal quality loss.

Memory layout (160 bytes, 16-byte aligned): geometry occupies 32 bytes, FP32 DC plus scale 16 bytes, 24 signed SH1–4 words 96 bytes, normal/stroke 8 bytes and deterministic trailing padding 8 bytes. SH metadata is synthesized by the quantized shader path; unused words are zero. Position/scale precision remains controlled by the per-chunk bounds.
