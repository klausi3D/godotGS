95 // Atlas-only sub-generation. The resident publisher splits its source_generation into a
96 // per-asset atlas hash (asset list + per-asset content_revision) and a per-frame instance
97 // hash (visibility, transform, opacity, wind, grading, etc). When this matches the cached
98 // value the publisher skips the expensive pack_gaussians_range loop and the four atlas
99 // storage-buffer uploads, going straight to the cheap instance-buffer + grading-buffer
100 // refresh. Bumped on the slow path; never bumped on instance-only updates.

102 // Cached on the slow path so the fast (instance-only) path can re-publish the contract

108 // Test instrumentation: increments every time the publisher actually re-runs the atlas
109 // pack loop. Lets regression tests assert that per-instance state changes (visibility,
110 // transform, opacity, etc) do NOT trigger an atlas repack.
111 uint64_t resident_atlas_pack_count = 0;
112 // Resident atlas VRAM-budget LOD clamp telemetry (#321 follow-up). Cached on the slow
113 // path so the fast (instance-only) path re-surfaces the same values. `source_count` is
114 // the full atlas splat count; the packed count is resident_atlas_gaussian_count above
115 // (== source_count when not reduced); `keep_ratio` is the global importance-thinning
116 // fraction applied per chunk. `reduced` is true whenever the atlas was clamped to fit
117 // the device VRAM budget (observable, never a silent drop).
118 bool resident_atlas_reduced = false;
119 uint32_t resident_atlas_source_count = 0;
120 float resident_atlas_keep_ratio = 1.0f;
