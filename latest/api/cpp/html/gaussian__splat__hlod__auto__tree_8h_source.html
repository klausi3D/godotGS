6// D2-3 driver: GsqAutoTreeSource -> TiledAutoTree -> WriterV4 (NONE or GSQ v1)
7// -> reopen every node, recompute metrics and compare pre-finalize digests ->
8// stage output and <stem>.manifest.json, then publish with per-file atomic
9// replacements and rollback on ordinary I/O errors. Native filesystems cannot
10// atomically replace TWO fixed names together: a crash/concurrent reader can see
11// a mixed pair. Hard-link backups preserve previous bytes until publication;
12// unsupported filesystems fail closed. Rollback filesystem failures preserve
13// recovery files and name their directory in the error, rather than deleting old
14// data. Callers must exclude external writers and validate the sidecar file SHA.
15// Only owned private staging/scratch directories are cleaned, never caller files.
16// codec="none" (default) preserves uncompressed output. codec="gsq" uses
17// gsq_v1_codec_params() for scratch and V4 output (header codec id 1).
18// Individual codec parameter overrides are not exposed by the bound API.
19//
20// Manifest schema godotgs-auto-tree-manifest/1:
21// tree_sha, source_fingerprint, input_file_sha256, input_manifest_sha256,
22// input_gen_sha, input_generator_params_sha (when available), build_params,
23// codec, nodes=[{stored_sha256, decoded_sha256}], totals,
24// levels=[{depth,node_count,eps_min,eps_median,eps_max}], content_generation,
25// output_file_sha256 and report. content_generation is an unsigned decimal
26// string (JSON numbers cannot retain all 64 bits). The codec block is unchanged
27// for none: {"codec":"none"}. GSQ records flat fields codec="gsq", codec_id,
28// sh_bits (three integers), opacity_bits, pos_step_m and zstd_level.
29// GSQ alone also records header_bounds={position_f32_bits:[x,y,z],
30// size_f32_bits:[x,y,z]} from the reopened output header. Each entry is the
31// unsigned IEEE754 float32 bit pattern stored as an integer, so JSON preserves
32// the exact written bounds. This output metadata is outside the tree_sha key;
33// output_file_sha256 covers the header. Codec-none manifest content is unchanged.
34// GSQ decoded_sha256 is gs_gsq::decoded_digest of read_node_payload's runtime
35// form (absolute leaves, relative interiors), checked against one encode/decode
36// of the original bake in V4's node-relative frame. Codec none retains its
37// existing raw Gaussian bytes followed by high-order SH bytes digest.
38// stored_sha256 hashes the entire V4 record for either codec.
39//
40// tree_sha hashes UTF-8 JSON::stringify(key, "", true, true), without newline,
41// where key={source_fingerprint,build_params,codec,input_file_sha256} and
42// build_params excludes worker_count. Record worker_count in manifest build_params
43// and report, but exclude it from the key (schedule independence, design section 6).
44// Frozen interior fields: merge_grid, reduction, node_max_splats, eps_growth,
45// max_eps_steps. Canonical numeric types are INT for leaf_max, max_tile_splats,
46// merge_grid, node_max_splats, max_eps_steps; FLOAT for reduction and eps_growth.
47// The entire codec block participates in the key. GSQ codec_id, sh_bits entries,
48// opacity_bits and zstd_level are INT; pos_step_m is FLOAT (double of the
49// CodecParams float, without decimal rounding). Codec none has no numeric fields.
50// Restore these schema types after JSON parsing before recomputing tree_sha.
51// Limits, paths, timings and memory are execution metadata only.
52// wall_usec measures through verified staging, excluding final manifest write
53// and publication so the returned and persisted report are identical. The whole
54// BakeResult is held in memory at T0 scale, then freed after spilling its nodes.
55// GSQ additionally reserves per-node digests and bounded single-node verification
56// encode/decode and reopen buffers, separately from WriterV4's working memory.
