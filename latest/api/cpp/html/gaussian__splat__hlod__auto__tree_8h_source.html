6// D2-3 driver: GsqAutoTreeSource -> TiledAutoTree -> WriterV4 (codec NONE)
7// -> reopen every node, recompute metrics and compare spill-time digests ->
8// stage output and <stem>.manifest.json, then publish with per-file atomic
9// replacements and rollback on ordinary I/O errors. Native filesystems cannot
10// atomically replace TWO fixed names together: a crash/concurrent reader can see
11// a mixed pair. Hard-link backups preserve previous bytes until publication;
12// unsupported filesystems fail closed. Rollback filesystem failures preserve
13// recovery files and name their directory in the error, rather than deleting old
14// data. Callers must exclude external writers and validate the sidecar file SHA.
15// Only owned private staging/scratch directories are cleaned, never caller files.
16// No GSQ node encoding/container until BV-C4: codec="gsq" must return
17// ERR_UNAVAILABLE / v4_gsq_output_requires_bv_c4.
18//
19// Manifest schema godotgs-auto-tree-manifest/1:
20// tree_sha, source_fingerprint, input_file_sha256, input_manifest_sha256,
21// input_gen_sha, input_generator_params_sha (when available), build_params,
22// codec={"codec":"none"}, nodes=[{stored_sha256, decoded_sha256}], totals,
23// levels=[{depth,node_count,eps_min,eps_median,eps_max}], content_generation,
24// output_file_sha256 and report. content_generation is an unsigned decimal
25// string (JSON numbers cannot retain all 64 bits). decoded_sha256 hashes runtime-form Gaussian
26// bytes followed by high-order SH bytes; stored_sha256 hashes the V4 record.
27//
28// tree_sha hashes UTF-8 JSON::stringify(key, "", true, true), without newline,
29// where key={source_fingerprint,build_params,codec,input_file_sha256} and
30// build_params excludes worker_count. Record worker_count in manifest build_params
31// and report, but exclude it from the key (schedule independence, design section 6).
32// Frozen interior fields: merge_grid, reduction, node_max_splats, eps_growth,
33// max_eps_steps. Canonical numeric types are INT for leaf_max, max_tile_splats,
34// merge_grid, node_max_splats, max_eps_steps; FLOAT for reduction and eps_growth.
