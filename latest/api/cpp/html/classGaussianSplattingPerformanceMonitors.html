Detailed Description

Manages Custom Performance Monitors for the Gaussian Splatting module.

This class registers custom performance monitors with Godot's Performance singleton, exposing GPU timings and rendering statistics to the editor debugger with zero overhead when the debugger is closed.

Monitors are organized into categories:

  • GPU Timings: Frame, cull, binning, prefix, sort, raster, resolve times
  • Statistics: Visible splats, projection success rates, rejection counts
  • Quality: Extreme aspect ratios, SH cache hit rates
  • Overflow: Tile overflow statistics
Note: Thread Safety: This class assumes single-threaded access from the main thread.
All renderer registration/unregistration and monitor polling occurs on the main thread as part of Godot's normal rendering and debugger update cycles. The internal renderer tracking lists (LocalVector) are not protected by mutexes. If future Godot versions introduce multi-threaded debugger polling, mutex protection should be added.
Note: Inherits from Object to enable callable_mp() for performance monitor callbacks.
This is required by Godot's Performance singleton which expects Object-based Callables.
