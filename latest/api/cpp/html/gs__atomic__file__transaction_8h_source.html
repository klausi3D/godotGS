8// Long-lived, durable, crash-atomic file write on a NATIVE OS handle
9// (docs/architecture/adr-beyond-vram-worlds.md §4.3, invariants W1/W9; BV-02).
10//
11// This is the durability layer the streaming world writer (BV-03a onward)
12// builds on. Unlike `gs_atomic_file_write` (gs_atomic_file_writer.h), which
13// streams through Godot `FileAccess` inside one call, this transaction stays open
14// across many appends and does NOT use `FileAccess`: FileAccess adds its own
15// backup temp, its flush is CRT-only (no fsync), and on Windows it opens
16// `_SH_DENYRW`, which blocks a second handle. Per the ADR:
17//
18// - Windows: `CreateFileW` (share-read, CREATE_NEW) on a sibling temp,
19// `WriteFile`, `FlushFileBuffers` on the same handle, `CloseHandle`, then
20// `MoveFileExW(MOVEFILE_REPLACE_EXISTING | MOVEFILE_WRITE_THROUGH)`.
21// Windows has no directory fsync.
22// - POSIX: `open(O_CREAT | O_EXCL)` on a sibling temp, `pwrite`, `fdatasync`
23// (`F_FULLFSYNC` on Apple), `close`, `rename`, then fsync the directory.
24//
25// Contract:
26// - Nothing exists at the final path, and a pre-existing final file is not
27// touched, until `commit()` performs the single atomic replace.
28// - `abort()`, the destructor, and every failure path close the handle and
29// remove the temp; the final path is never opened, written or removed by
30// them. (A process crash can leave the temp behind; it never replaces the
31// target.)
32// - There is no backup-swap fallback: if the atomic replace fails, `commit()`
33// reports the error, removes the temp and leaves the target as it was.
34// - Writes only grow the file or rewrite bytes already written (`write_at`
35// with `offset + size <= get_size()`, e.g. a final header rewrite, W2); no
36// write can leave a hole.
37// - Any failure poisons the transaction: it is cleaned up immediately, the
38// error stays readable through `get_error()` / `get_error_message()`, and
39// further calls return that error until the next `begin()`.
40//
41// Not thread-safe: one transaction is driven by one thread at a time.
42class GSAtomicFileTransaction {
43public:
44 enum class State : uint8_t {
45 IDLE, // never begun, or ready for a new begin()
46 OPEN, // temp exists, writes accepted
47 COMMITTED, // the final path names the new file
48 ABORTED, // aborted by the caller or the destructor; no temp
49 FAILED, // a step failed; cleaned up; see get_error()
50 };
