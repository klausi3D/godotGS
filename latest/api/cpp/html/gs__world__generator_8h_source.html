15// Synthetic test-world generator (BV-05; docs/architecture/adr-beyond-vram-worlds.md
16// §6.1-§6.4, D-2, §4.1 sidecar manifest, W8).
17//
18// One seeded, counter-hash, re-iterable content definition for every tier:
19//
20// - T0 4,194,304 splats, 512 x 512 m (controls, F/k sweep, identity, smoke);
21// - A 201,326,592 splats, 2,048 x 2,048 m, the exact §6.2 content table;
22// - A-mini A's densities on 2 x 2 tiles (13,881,322 splats), for local evidence;
23// - T-smoke 262,144 splats on one tile, for unit tests;
24// - T-ref not a tier of its own: a chunk subset of a tier (generate_world with a
25// selection), byte-identical to the parent's chunks.
26//
27// Content. A world is a grid of 256 m tiles over an open plain, with towns, one
28// corridor of two walls, low-alpha foliage clusters and coded beacons (4 per tile).
29// Every class count is exact: towns, walls and foliage are density x integer area,
30// beacons a fixed splat count, and the plain is the remainder, apportioned to chunks
31// by largest remainder over integer areas. The plan asserts the declared total.
32//
33// Chunks. 32 m cells aligned to the world origin (the HLOD lattice), subdivided by
34// powers of two down to 8 m until a cell holds <= max_chunk_splats (65,536). Chunks are
35// written in Morton order. Inside a chunk the splats are a stratified merge of the
36// chunk's content parts (a prefix keeps every part's share) and each part is an
37// additive-recurrence (R2) low-discrepancy sequence, so a prefix is a spatial sample.
38//
39// SH. Degree 3 from spatially correlated value-noise fields (4 latent channels,
40// smoothstep-bilinear lattices at the correlation length and finer octaves); each
41// coefficient is a fixed seeded mix of the latents plus a small per-splat jitter.
42// sh.field_amp_q8 = 0 turns the field off (hash-noise SH), the negative control.
43//
44// Determinism. Every value is computed in integer or exact dyadic arithmetic: no libm
45// call, no float division or square root on the per-splat path, and the only rounding
46// is the final narrowing of a fixed-point position to float (toward negative infinity,
47// so a splat never lands on its cell's upper edge). The bytes therefore do
48// not depend on FMA contraction, fast-math reassociation or the compiler, and the
49// pinned golden digests in the [WorldGenerator] doctests hold on every platform.
50//
51// Streaming. generate_world() drives gs_world_writer::Writer in REITERABLE mode: each
52// pass regenerates the chunks one at a time (the writer refuses a pass 2 that diverges
53// from pass 1, which makes it a determinism check too). RAM is the plan (features,
54// chunk table, a few hundred kB for Tier A) plus one chunk buffer (<= 65,536 splats,
55// about 19 MB); the world is never materialized (I-8).
56//
57// Manifest (§4.1, W8). After finalize() the file is read back sequentially and every
58// per-chunk gaussian / SH digest and the file digest are recomputed from disk and
59// compared with the digests taken from memory while generating. Only then is the
60// sidecar <stem>.manifest.json written (atomically). It carries the parameters and
61// generator_params_sha, gen_sha, writer and codec versions, the exact content table,
62// every feature (towns, walls, foliage, beacons with their codes), and per chunk:
63// cell, Morton key, counts per class, the chunk-table AABB/centre/radius, byte ranges
64// and SHA-256 digests. The manifest holds no timing, so its bytes are deterministic too.
65//
66// GSQ v1 (GenerateOptions::codec_id, BV-C7). The writer encodes, decodes and validates every
67// page (W12). The read-back verifies every page's stored digest and records per chunk its page
68// run (first page, page count, byte span and the SHA-256 of that span); the manifest's "codec"
69// block carries the page count, the stored bytes and the SHA-256 of the decoded digest set
70// (every page's decoded digest in page order). A lossy codec has no "generated == stored"
71// identity, so no per-chunk generated-bytes digest is recorded for it.
