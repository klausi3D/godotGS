Detailed Description

Helper macros to reduce boilerplate in debug overlay setter implementations.

These macros consolidate repetitive patterns found across:

  • DebugOverlaySystem (12 nearly-identical setters)
  • RenderDebugStateOrchestrator (7 nearly-identical setters)
  • debug_overlay_methods.cpp (delegation methods)

Usage Example: GS_DEBUG_OVERLAY_SETTER_IMPL(show_tile_grid) expands to: void DebugOverlaySystem::set_show_tile_grid(bool p_enabled) { if (options.show_tile_grid != p_enabled) { options.show_tile_grid = p_enabled; _mark_dirty(); } }
