71 // #831: push the renderer-wide screen-space overlay flags as the union over
72 // every node bound to this node's renderer. Edge-triggered against the last
73 // union any node pushed to that renderer, so an unchanged node does NOT
74 // re-assert the flags every frame -- that re-assertion is what silently
75 // reverted every GaussianSplatRenderer::set_debug_show_*() call one frame
76 // after it was made.
77 //
78 // When the union actually CHANGES, this also fans HUD-control reconciliation
79 // out to the renderer's peers: the flags are renderer-wide but the control is
80 // drawn by exactly one node (the HUD owner elected by can_own_debug_hud), so a
81 // peer flipping show_performance_hud / show_residency_hud has to reach that
82 // owner or the flag is enabled with no HUD on screen (#839 round 2,
83 // finding 1). Unchanged pushes stay free.

85 // #839 round 4, thread 1: is this node the ONE node that draws its renderer's
86 // debug HUD? Weaker than GaussianSplatNodeRendererHelper::can_apply_renderer_settings()
87 // on purpose -- hosting a CanvasLayer of renderer-wide stats does not require
88 // owning the renderer's scene data, and requiring it left a world-backed
89 // shared renderer with NO eligible node at all.
90 bool can_own_debug_hud() const;
91 // #839 round 3, thread B: recompute and push the union from the renderer's
92 // CURRENT registered node set, with no "self" seed. push_debug_overlay_union()
93 // cannot do this job when the observing node is the one that just left: it
94 // early-returns on the out-of-tree owner, and even if it did not it would
95 // contribute the departed node's own flags. Needed for the 1 -> 0 transition,
96 // where the peer walk in _notify_renderer_peers_shared_state_changed() has
97 // nobody left to delegate to but the renderer is still alive on a
98 // GaussianSplatWorld3D submission, so the departed node's tile-grid or
99 // heatmap request would stay enabled forever.
100 static void reconcile_debug_overlay_union_for_renderer(GaussianSplatRenderer *p_renderer);
101 // #839 round 7: the overlay union's peer set is "every node BOUND to the
102 // renderer", which is strictly larger than "every node the scene director has
103 // an instance record for": GaussianSplatNode3D::_register_shared_renderer()
104 // returns before registering when the node has no splat asset, no
105 // renderer_data and no runtime asset, yet such a node still resolves and
106 // holds the world's shared renderer and still owns the four overlay
107 // properties. Two of them therefore each saw an empty peer list and the last
108 // one to push retracted the other's request -- last-writer-wins, the very
109 // defect #831 removes.
110 //
111 // #839 round 8: the record's lifetime tracks the node's `renderer` Ref and is
112 // INDEPENDENT of whether the node has content -- register from
113 // GaussianSplatNodeRendererHelper::ensure_renderer() (bind), unregister ONLY
114 // from GaussianSplatNode3D::_unbind_renderer_binding_record() (unbind: Ref
115 // dropped / left the tree / left the world). Do NOT call unregister from a
116 // content path; `set_splat_asset(null)` on an in-tree node is not an unbind.
117 // The full invariant, and why the unbind must be explicit rather than derived
118 // from is_inside_tree(), is stated at `g_renderer_bound_nodes` in
119 // gaussian_splat_node_helpers.cpp.
120 static void register_renderer_bound_node(GaussianSplatRenderer *p_renderer, GaussianSplatNode3D *p_node);
