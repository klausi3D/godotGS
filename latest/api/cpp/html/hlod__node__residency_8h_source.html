4// ADR docs/architecture/adr-hlod-streaming.md sections 6.6, 14.1 and 14.2 (package D1).
5//
6// CPU-only residency model for HLOD tree nodes. It is the node-level front of the streaming system's page
7// allocator (GaussianAtlasAllocator, #1088) and follows the same contracts the chunk streamer uses:
8// whole-run admission, per-request generations (the #1177 upload-sequence idea: a completion whose ticket is
9// not the node's current one is dropped), a retirement delay before a freed run may be reused, and an
10// eviction order of outside the protected closure, then least recently drawn, then finest level first.
11// It owns no GPU resource and performs no I/O: the renderer glue (renderer/hlod_node_streamer.*) packs and
12// uploads, this class decides what is requested, what may be freed and what counts as resident-ready.
13//
14// ABSENT --request--> LOADING --begin_upload--> UPLOADING --finish_upload(ok)--> RESIDENT
15// | | \--finish_upload(fail)--> FAILED
16// \--fail_load--> FAILED \--cancel--> ABSENT (run retires, ticket dead)
17//
18// Only RESIDENT nodes are visible to the selector (resident_mask()). A node is RESIDENT only after its
19// payload was validated, completely uploaded and finish_upload() was called for the current ticket on the
20// current world and device generation; an allocated or partly uploaded run is accounted for separately.
21//
22// Package F1 (ADR 14.5, editable regions): an edit replaces the payload of leaf nodes and makes their ancestors STALE.
23// stage_edit() admits the whole edit or none of it: a reserved SHADOW run for every edited leaf (the old run keeps
24// serving the old content, which stays consistent until the flip), one ticket per leaf, and a hold on
25// the children of every stale node (the replacement cut the selector will draw), which therefore
26// cannot be evicted. Nothing drawable changes while the edit is only staged.
27// edit_prefetch() the children of stale nodes that still need loading, as ordinary demand.
28// finish_shadow() a packed shadow payload arrived (ticket checked against world, device and edit generation).
29// commit_edit() the atomic publication boundary: once every shadow is ready and every replacement child is
30// RESIDENT, each edited leaf takes its shadow run (the old run retires, any in-flight ticket of the
31// old content dies) and every stale node is dropped (mask 0, run retired, never requested again).
32// cancel_edit() gives the reservation back; the world is exactly as before the edit was staged.
33// One edit is staged at a time and its revision must follow the committed one (expected prior revision).
34//
35// Threading: not thread-safe; call from the thread that owns the selection state (the render thread).
