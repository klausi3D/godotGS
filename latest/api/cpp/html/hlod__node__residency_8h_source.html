6// ADR docs/architecture/adr-hlod-streaming.md sections 6.6, 14.1 and 14.2 (package D1).
7//
8// CPU-only residency model for HLOD tree nodes. Owns an HLOD-only single-page pool and follows the same
9// lifetime contracts the chunk streamer uses:
10// whole-run admission, per-request generations (the #1177 upload-sequence idea: a completion whose ticket is
11// not the node's current one is dropped), a retirement delay before a freed run may be reused, and an
12// eviction order of outside the protected closure, then least recently drawn, then finest level first.
13// It owns no GPU resource and performs no I/O: the renderer glue (renderer/hlod_node_streamer.*) packs and
14// uploads, this class decides what is requested, what may be freed and what counts as resident-ready.
15//
16// ABSENT --request--> LOADING --begin_upload--> UPLOADING --finish_upload(ok)--> RESIDENT
17// | | \--finish_upload(fail)--> FAILED
18// \--fail_load--> FAILED \--cancel--> ABSENT (run retires, ticket dead)
19//
20// Only RESIDENT nodes are visible to the selector (resident_mask()). A node is RESIDENT only after its
21// payload was validated, completely uploaded and finish_upload() was called for the current ticket on the
22// current world and device generation; an allocated or partly uploaded run is accounted for separately.
23//
24// Package F1 (ADR 14.5, editable regions): an edit replaces the payload of leaf nodes and makes their ancestors STALE.
25// stage_edit() admits the whole edit or none of it: a reserved SHADOW run for every edited leaf (the old run keeps
26// serving the old content, which stays consistent until the flip), one ticket per leaf, and a hold on
27// the children of every stale node (the replacement cut the selector will draw), which therefore
28// cannot be evicted. Nothing drawable changes while the edit is only staged.
29// edit_prefetch() the children of stale nodes that still need loading, as ordinary demand.
30// finish_shadow() a packed shadow payload arrived (ticket checked against world, device, generation and run).
31// Packing alone is not ready: finish_shadow_transfer() marks the whole reserved run transferred.
32// commit_edit() the atomic publication boundary: once every shadow is transferred and every replacement child is
33// RESIDENT, each edited leaf takes its shadow run (the old run retires, any in-flight ticket of the
34// old content dies) and every stale node is dropped (mask 0, run retired, never requested again).
35// cancel_edit() gives the reservation back; the world is exactly as before the edit was staged.
36// One edit is staged at a time and its revision must follow the committed one (expected prior revision).
37//
38// Threading: not thread-safe; call from the thread that owns the selection state (the render thread).

49enum FailureClass : uint8_t { FAILURE_PERMANENT = 0, FAILURE_RETRY_LATER };
50
51// Load-error policy: ERR_BUSY, ERR_OUT_OF_MEMORY, ERR_UNAVAILABLE and ERR_SKIP
52// retry later (ERR_SKIP reaches HLOD only for read-service cancellation/shutdown).
53// All other errors fail closed: corrupt records/digests/decodes,
54// layout mismatches, missing/unopenable files, changed lengths, EOF and I/O errors.
55inline FailureClass classify_load_error(Error p_error) {
56 switch (p_error) {
57 case ERR_BUSY:
58 case ERR_OUT_OF_MEMORY:
59 case ERR_UNAVAILABLE:
60 case ERR_SKIP:
61 return FAILURE_RETRY_LATER;
62 default:
63 return FAILURE_PERMANENT;
64 }
65}
