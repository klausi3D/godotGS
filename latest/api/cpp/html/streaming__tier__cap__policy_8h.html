Detailed Description

Shared resolution of streaming tier-cap policy from ProjectSettings.

This header centralizes the StreamingTierCapPolicy struct and the three resolver helpers that were previously duplicated, near-identically, in streaming_upload_pipeline.cpp and streaming_vram_regulator.cpp. All ProjectSettings reads route through the canonical gs::settings accessors.
