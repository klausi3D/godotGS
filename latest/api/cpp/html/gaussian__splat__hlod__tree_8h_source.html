4// Hierarchical LOD tree of a GaussianSplatWorld (ADR docs/architecture/adr-hlod-streaming.md,
5// slice S1a: format + bake). Nothing in the renderer reads the tree yet (S2 adds the cut).
6//
7// World lattice (§6.1, decision 5; ADR head 74bf3699702). One global lattice fixed by the world
8// frame: origin O (double; (0, 0, 0) unless the world sets one) and power-of-two cells. A cell is
9// (e, ix, iy, iz): edge 2^e metres (e signed, >= -16), signed 64-bit indices, corner
10// O + (ix, iy, iz) x 2^e, exact in double. Cell boundaries never depend on the data, so two
11// worlds, or a world before and after an edit, agree on every boundary.
12//
13// Origin-centred root (implementation rule, reported to the ADR author): the planes through O
14// are boundaries at every scale, so content that straddles them (most scans are centred on the
15// origin) lies in no single lattice cell. The root is then the cube [O - 2^e, O + 2^e) with the
16// flag kNodeFlagOriginCentredRoot and address (e, 0, 0, 0); its children are the lattice cells
17// (e, {-1, 0}^3), i.e. ordinary cells. Otherwise the root is the smallest lattice cell holding
18// every centre.
19//
20// Positions (§6.2, decision 6). Every payload splat position, and every node AABB, is float32
21// relative to the CENTRE of its node's cell. Interior payloads are kept that way in memory.
22// The leaf payload of a loaded or baked world is ALSO handed to today's runtime as absolute
23// float32 (GaussianData, or the file-backed source with per-leaf frames), so a renderer that
24// knows nothing of the tree draws exactly the original splats until S2.
25//
26// Payload index space. [0, leaf_splat_count) are the original splats, reordered so that every
27// leaf is contiguous (leaves in depth-first order, so a subtree's leaves are contiguous too) and
28// importance-ordered; [leaf_splat_count, total) are interior payloads, root first in node-table
29// (breadth-first) order, each importance-ordered.

189// Validates a tree against the payload it indexes. Fails closed: returns false and sets r_reason
190// on the first violated invariant (§7; persistence is R3).
191// - lattice: finite origin; every cell has e in [-16, 62] and |index| < 2^52;
192// - shape: node 0 is the root; every other node's parent precedes it; children are contiguous,
193// follow their parent, point back to it and number at most 8; the child ranges cover every
194// non-root node exactly once (one tree, no cycles, no orphans);
195// - cells: a child is an octant of its parent's cell (e - 1, index = 2 x parent + bit), one of
196// the origin-centred root's cells (e, {-1, 0}), or, with split_by_index / grouped_leaf, the
197// parent's own cell; only the root may be origin-centred;
198// - payload: counts in [1, 16384]; leaf payloads tile [0, leaf_count) and interior payloads tile
199// [leaf_count, leaf_count + interior_count) without gaps or overlap;
200// - geometry: finite fields, aabb_min <= aabb_max, radius >= 0, each child's world AABB inside its
201// parent's (to float32 rounding of the cell offsets); geometric error 0 on leaves, > 0 inside,
202// monotone up the tree;
203// - kinds and flags: leaf <=> no children <=> LEAF kind; interior nodes MERGED or SELECTED; no
204// unknown flag bits; grouped_leaf only on leaves; heights consistent;
205// - instances: every instance references a top-level LEAF; the top-level tree has the same shape
206// rules with empty payloads; transforms finite.
207bool gs_hlod_validate_tree(const GaussianSplatHlodTree &p_tree, String *r_reason);
