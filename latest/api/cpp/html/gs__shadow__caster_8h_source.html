4// GPU half of the HLOD splat shadow caster (#1095, #1163): one graphics pipeline (shaders/gs_shadow_caster.glsl) that
5// draws the main view's HLOD draw list as depth-only Gaussian quads into the shadow-atlas rect Godot hands a directional
6// shadow pass. Planning and the depth convention live in hlod_shadow_caster_plan.h (device-free, CPU-tested).
7//
8// Ownership: the shader is compiled on the device passed to draw() and freed through that recorded owner by clear()
9// (renderer teardown) or when draw() sees a different device. Uniform sets come from UniformSetCacheRD, which drops a set
10// as soon as any buffer it binds is freed, so no set outlives the HLOD bundle it names. Pipelines live in the
11// PipelineCacheRD, cleared with the shader.
