Detailed Description

The eight rendering/gaussian_splatting/animation/wind_* settings.

THE reader for the group. It used to be read in three places with three hand-kept copies of the same StringName list – the baseline parameter producer and the cull/lighting signature hash (both in renderer/render_pipeline_stages.cpp) and the depth/sort pass uniform fill (interfaces/gpu_sorting_pipeline.cpp) – and in zero places by the painterly producer, which is #1018: painterly left wind_time_seconds at its struct default 0.0f forever, so per-node wind rendered frozen mid-sway instead of animating.

All three copies are gone. tests/ci/check_render_param_family_producers.py rule 8 fails the build if a second file reads rendering/gaussian_splatting/animation/wind_* again – the sort-pass copy survived the first version of that guard because it inspects TileRenderParams producers and the sort pass fills InstanceDepthParamsGPU instead.

Read it with get_wind_settings() and write it with apply_wind_to_render_params() so a producer cannot populate half the group.
