163 // Push the material to the shared renderer only when the NODE changed it.
164 //
165 // apply_renderer_settings() runs every frame (update_splats() calls it
166 // before the render_state_dirty check), so an unconditional push would make
167 // the node overwrite the renderer's material on every frame -- with an

169 // GaussianSplatRenderer.painterly_material, the script route that is the

172 // silently fall back to the baseline raster.
