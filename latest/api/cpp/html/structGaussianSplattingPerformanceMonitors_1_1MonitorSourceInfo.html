Detailed Description

Which renderers the process-global custom monitors are currently reporting.

GaussianSplatPerformanceOverlay (#1084) reads per-renderer rows from the custom monitors, which follow the most recently registered renderer (register_splat_renderer()), while its GPU-pass rows come from its own target renderer. It shows a monitor row only when this says the monitors unambiguously describe that same target.
