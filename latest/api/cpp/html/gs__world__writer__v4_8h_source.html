6// BV-18a/BV-C4 out-of-core writer. CodecParams selects both scratch encoding and
7// the V4 header codec id: none preserves the original bytes; GSQ emits one
8// node-relative GSQ page per record. W13 post-assembly verification belongs to BV-18b.
9//
10// Append runtime-form bodies (absolute leaf positions, relative interiors) in
11// any order. One scratch file per (bucket, depth), beneath the caller's scratch
12// directory. At most kMaxOpenSpillSegments (64) native segment handles stay open;
13// LRU eviction closes without deleting. Reopens append at the recorded length
14// or read during assembly. Closed files remain owned until deletion/cleanup.
15// Scratch is not fsynced or committed; only the final output is durable.
16// GSQ pages preserve node order, are encoded, decoded and validated
17// before append (W12/W14). Leaf metrics describe the reader's reconstruction
18// after node-relative serialization; interior metrics use the decoded form.
19// As in write_package (D-7), inexact centre reconstruction on that runtime
20// form refuses with ERR_UNAVAILABLE / v4_center_reconstruction_not_exact;
21// failure removes all owned scratch files and preserves the destination.
22// Codec none spills losslessly. Finalization derives depth/centre/leaf from topology,
23// reuses gs_hlod_validate_tree, requires canonical BFS and exactly one use of
24// every handle, and writes bodies in BFS order. content_generation uses digests
25// of the actual stored V4 output bodies (node-relative, GSQ-compressed when selected).
26// GSQ finalization first decodes one output node at a time in reverse BFS and
27// unions its three-sigma support with the bake AABB/sphere and final child
28// bounds. A moved AABB midpoint preserves the entire original sphere. Bounds
29// use the bake's outward rounding; validation tolerances are unchanged. All
30// bounds are final before record serialization/hashing; codec none skips this
31// pass and retains the bake bounds and original bytes. This extra GSQ read/decode
32// pass uses the existing admitted per-node buffers and node tables, not a second
33// resident tree of payloads. Scratch is retained until the BFS write pass.
34// GSQ also unions spec.bounds with the final root's double world extent and
35// rounds the float32 header position/size outward using double(position) +
36// double(size), exactly as the normal resource loader checks enclosure. An
37// unrepresentable union fails with v4_header_bounds_unrepresentable; no bounds
38// are discarded. This precedes header identity, record and index hashing.
39// Codec none retains spec.bounds verbatim, including its original header bytes.
40//
41// W1: publish through GSAtomicFileTransaction only after successful assembly.
42// Failure, abort and destruction remove all owned temp/segment files and leave
43// any pre-existing destination byte-intact. Delete each segment immediately
44// after copying its last body. A crash mid-assembly is NOT resumable: the cache
45// owner must sweep orphan files and re-bake. The writer owns only its files.
46// Like the plain writer, this inherits GSAtomicFileTransaction's POSIX caveat:
47// a directory-fsync error after rename reports a durability failure with the
48// new destination already in place; it cannot roll back the atomic replace.
49//
50// Limits retain the plain writer's required fields and reasons: limits_unset,
51// limit_scratch, limit_output, limit_ram, deadline (ERR_TIMEOUT), cancelled
52// (ERR_SKIP). Check stop requests within <= 1 MiB of I/O and before commit.
53// RAM admission conservatively includes serialization buffers and codec working
54// contexts. Metadata cycles and Object/Callable/Signal values are refused before
55// JSON stringification: arbitrary user-code stringification has no memory bound.
56// One driving thread; only request_cancel/get_progress may cross threads.
