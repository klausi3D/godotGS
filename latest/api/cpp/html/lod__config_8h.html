Detailed Description

Distance-based LOD configuration for Gaussian Splatting streaming.

Implements the Octree-GS LOD selection formula: L = floor(min(max(log2(d_max/d), 0), K-1))

Where: d = distance from camera to chunk/splat d_max = maximum render distance K = number of LOD levels L = selected LOD level (0 = highest detail, K-1 = lowest)

LOD reduction strategies:

  • Splat skipping: Skip every Nth splat based on LOD level
  • SH band reduction: Use fewer spherical harmonics bands at distance
  • Opacity fade: Reduce opacity for distant splats
