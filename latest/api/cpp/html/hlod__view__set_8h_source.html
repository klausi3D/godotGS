4// ADR docs/architecture/adr-hlod-streaming.md sections 14.1, 14.2 and 6.9 (package B2).
5//
6// CPU-only contracts that sit on top of the existing S2a selector (`CutHistory`); there is no
7// second selector. Nothing here is a bound API or a registered class. The renderer owns its
8// per-view cut state through this ViewSet (RenderFrameContextManager, package B3).
9//
10// - NodeKey / NodeVersion: stable node identity and content identity, independent of atlas
11// address and of node-array order.
12// - SelectionSnapshot: an immutable input (hierarchy/content revision, transforms, residency,
13// budgets, per-view parameters). Selection only reads it.
14// - Frame (package C, ADR 14.3): the snapshot carries the render-frame origin (precise) and its revision.
15// Instance placements and node centres are precise; selection works in the origin-relative float frame
16// derived from them. A different origin revision invalidates every view's cut history and published draw
17// set before anything is selected, so old and new offsets never mix.
18// - ViewSet: each admitted view owns its cut histories and its published draw records.
19// One physical byte budget covers all views and instances: shared payload is charged once per
20// asset, per-view sort/record/draw allocations are charged once per admitted view.
21// Admitting a view either reserves everything it needs or returns an explicit refusal; no
22// other view's caps, history or published draw records are touched by either outcome.
23//
24// Threading: not thread-safe; call from the thread that owns the selection state.
25

146// Desired(view), demand only (ADR 14.1): a node the quality rule wants resident that is not. It carries no
147// atlas address and never makes anything drawable; the residency layer decides what is requested and when a
148// node counts as resident-ready. Ordered by the selector's refinement priority (highest first), children of
149// one parent consecutive.
150struct DesiredRecord {
151 uint64_t instance_key = 0;
152 uint32_t node = 0; // Index into the asset's node table; valid only for this snapshot.
153 // false: a node the view wants and does not have (request it). true: a node that is already resident and is
154 // part of the target the view is building (the resident part of an incomplete bootstrap frontier): keep it,
155 // do not request it.
156 bool keep = false;

220 // Runs one selection per admitted view that appears in the snapshot, in ascending view key, and stores
221 // the per-view results (see results()). In steady state (same instance and view sets, same node counts)
222 // it performs no heap allocation: every buffer was sized by admit_view(), and the only growth is the
