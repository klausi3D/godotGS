5// Test-only S1b matched-arm quality exporter (ADR docs/architecture/adr-hlod-streaming.md §9 S1b,
6// §14.7, §15). NOT a runtime or publication API and not shipped: CPU-only, main thread.
7//
8// Given one quality bake with an attached gs_hlod::CandidateCapture and ONE explicit complete cut,
9// it assembles four splat sets over the same domain:
10// SAT the MERGED candidate of every cut node,
11// A-area the SELECTED candidate of every cut node,
12// S1b the winner the baker kept at every cut node,
13// reference the independent all-leaf set rebuilt from the bake INPUT,
14// and writes each through the existing resident-uncompressed .gsplatworld saver with a strict
15// native round trip. Nothing is pruned, cropped or filled to reach a count: any mismatch fails with
16// a typed status.
17//
18// Matching contract. At each interior cut node the baker builds SAT and A-area from the same
19// children (the baker's chosen child payloads, i.e. the S1b-chosen subtree below) with the same
20// candidate count, so the three arms have the same count per node and in total by construction;
21// this is verified, never assumed. The cut leaves are original splats in all three arms.

28// Predeclared, explicit resource contract. The runtime-cut oracle's own limits
29// (gs_hlod::runtime_cut::MAX_*) are NOT changed; this is a separate opt-in contract.
30struct Admission {
31 // Leaves and interiors are capped SEPARATELY ("8M leaves plus interiors"): an 8,000,000-leaf scan must
32 // not be refused because its interiors do not fit in the leaf budget.
33 uint64_t max_leaf_splats = 0; // original splats of the bake input
34 uint64_t max_interior_splats = 0; // interior payload splats the bake produced
35 // Optional combined cap on leaves + interiors (0 = none). Only default_contract() sets it, to mirror
36 // the runtime-cut oracle's single 65,536 limit exactly.
37 uint64_t max_total_splats = 0;
38 uint32_t max_nodes = 0;
39 // Cap on capture + arms + reference bytes (payload + SH + 1 KiB/node), checked against the actual
40 // cut before any arm is allocated. Physical-memory admission is a separate, caller-side check.
41 uint64_t max_bytes = 0;
42
43 // Mirrors gs_hlod::runtime_cut::MAX_INPUT_SPLATS / MAX_NODES / MAX_ALLOCATION_BYTES.
44 static Admission default_contract();
45 // 8,000,000 leaves + a separate 3,000,000 interior cap, 262,144 nodes, 12 GiB. Interior bound: every
46 // interior payload is <= ceil(sum of its children's payloads / 4) (the baker's winner_bound), so per
47 // level the total shrinks 4x and sum(interiors) <= L/3 + 0.75 * nodes = 2,666,667 + 196,608 = 2,863,275
48 // for L = 8,000,000 and 262,144 nodes; 3,000,000 rounds that up. A cut is <= L, so the arms
49 // (3 * cut + L reference) are at most 32M splats = 9.2 GB at SH3 (288 B/splat); with the capture of
50 // both candidates (<= 2 * 3M * 288 = 1.7 GB) and 1 KiB/node the worst case is ~11.2 GB < 12 GiB.
51 static Admission large_contract();
52};
