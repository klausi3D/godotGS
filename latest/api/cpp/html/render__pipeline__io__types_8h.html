Detailed Description

Pipeline stage input/output type definitions.

Standalone types for the renderer pipeline stages (cull, sort, raster, composite). Extracted from GaussianSplatRenderer to allow orchestrators and pipeline stages to depend on narrow contracts instead of the full renderer header.
