17// Streaming world writer (docs/architecture/adr-beyond-vram-worlds.md §4.2-§4.5).
18//
19// BV-03a scope: the PLAIN_V3 target, codec "none", in both source modes, built on
20// GSAtomicFileTransaction (BV-02). It writes a plain v3 .gsplatworld without ever
21// holding the world in memory, and its output is byte-identical to
22// ResourceSaver::save of the same world (§4.5; proven by the [WorldWriter]
23// doctests).
24//
25// Not here yet (later packages, per §10): Limits, preflight, cancel, progress and
26// the Report (BV-03b); the GSQ codec (BV-C3); PAGED_V4 (BV-18a). The API grows
27// into the §4.3 signature as those land.
28//
29// Usage. Declare the world up front in a PlainSpec; then feed it chunk by chunk in
30// chunk order (W3). One "chunk" is one append unit: with write_chunk_table it is
31// also one record of the plain chunk table, whose indices are the contiguous range
32// of splats that chunk appended. Without it the units only frame the stream.
33//
34// Writer w;
35// w.begin_plain(path, spec, CodecParams(), SourceMode::REITERABLE);
36// for (uint32_t pass = w.current_pass(); pass != Writer::kNoPass; pass = w.current_pass()) {
37// for (each chunk c, in the same order every pass) {
38// w.append_chunk(desc[c], gaussians[c], sh_high[c], count[c]);
39// }
40// }
41// w.finalize();
42//
43// - REITERABLE: the source is walked once per pass. Pass 1 consumes the
44// gaussians, pass 2 (only when the world has high-order SH) consumes the SH;
45// the pointer a pass does not consume is ignored and may be null. Pass 2 must
46// replay the same chunk stream: a chunk whose count or descriptor differs from
47// pass 1 is refused. Nothing is spilled.
48// - SINGLE_PASS: one walk. Gaussians go to the output, high-order SH to a scratch
49// sibling that finalize() copies behind them and then deletes.
50//
51// A pass ends when it has received exactly `spec.chunk_count` chunks; the writer
52// then advances on its own. Declared means exact (W4): a chunk beyond the
53// declared count, a splat beyond `spec.splat_count`, a pass that ends short of
54// `splat_count`, or finalize() before every pass has completed all fail with a
55// "count_mismatch" message, and nothing is written to the final path.
56//
57// Invariants kept here (§4.4): W1 (nothing at the final path before finalize()
58// returns OK; on any failure, abort() or the destructor the temp and scratch are
59// removed and a pre-existing final file stays byte-intact), W2 (writes only grow
60// the file, apart from the final header rewrite), W3, W4, W5 (RAM is the chunk
61// table plus one 1 MiB slice; index lists are generated, never held), W6
62// (structural validity at append time, with the plain loader's rules), W7
63// (output bytes are a pure function of the spec and the appended stream), W9 (via
64// GSAtomicFileTransaction) and the structural part of W11 (begin_plain refuses a
65// spec the plain loader would refuse).
66//
67// Reader suspension (#714). On Windows an open reader denies the delete access
68// the atomic replace needs, and a world that is being streamed keeps pooled read
69// handles to exactly this file. finalize() therefore flushes first and then holds
70// StagedFileChunkPayloadSource::ScopedReaderSuspend on the destination across the
71// replace only. If in-flight reads do not drain within its bounded wait, the
72// replace is not attempted: finalize() returns ERR_BUSY, removes the temp and
73// leaves the destination as it was. (On POSIX the guard is a no-op: rename()
74// replaces a file readers still hold open.)
75//
76// Not thread-safe: one writer is driven by one thread.
