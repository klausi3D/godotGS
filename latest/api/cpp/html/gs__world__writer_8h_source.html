20// Streaming world writer (docs/architecture/adr-beyond-vram-worlds.md §4.2-§4.5).
21//
22// BV-03a scope: the PLAIN_V3 target, codec "none", in both source modes, built on
23// GSAtomicFileTransaction (BV-02). It writes a plain v3 .gsplatworld without ever
24// holding the world in memory, and its output is byte-identical to
25// ResourceSaver::save of the same world (§4.5; proven by the [WorldWriter]
26// doctests).
27//
28// BV-03b: Limits, preflight, cancel, progress and the Report (§4.3, W10, W11); see
29// the Limits block below. Not here yet: PAGED_V4 (BV-18a).
30//
31// Codec GSQ v1 (BV-C3, container BV-C5a). The codec stage is gs_gsq::PageBuilder
32// (io/gsq/gsq_page_builder.h): it turns each appended chunk into importance-ordered,
33// Morton-inside, constant-grouped pages that are encoded, decoded and validated
34// before use (W12) and carry their stored and decoded digests (W15). With
35// codec_id 1 the writer produces plain v3 with flag bit 7 (paged GSQ chunks; layout
36// in gaussian_splat_world_format.h): one run of pages per chunk, in page order, then
37// the paged chunk table, the page table (offset, size, extent, both digests per page)
38// and the metadata. The codec block is written into the file's paged extension as
39// given (W16). It needs write_chunk_table (the chunk table is the page directory)
40// and SH degree <= 3 with the full high-order layout. Every source mode takes a
41// single pass: the SH travels inside the pages. The file size is known only once
42// finalize() returns OK.
43//
44// Usage. Declare the world up front in a PlainSpec; then feed it chunk by chunk in
45// chunk order (W3). One "chunk" is one append unit: with write_chunk_table it is
46// also one record of the plain chunk table, whose indices are the contiguous range
47// of splats that chunk appended. Without it the units only frame the stream.
48//
49// Writer w;
50// w.begin_plain(path, spec, CodecParams(), SourceMode::REITERABLE, limits);
51// for (uint32_t pass = w.current_pass(); pass != Writer::kNoPass; pass = w.current_pass()) {
52// for (each chunk c, in the same order every pass) {
53// w.append_chunk(desc[c], gaussians[c], sh_high[c], count[c]);
54// }
55// }
56// w.finalize();
57//
58// - REITERABLE: the source is walked once per pass. Pass 1 consumes the
59// gaussians, pass 2 (only when the world has high-order SH) consumes the SH;
60// the pointer a pass does not consume is ignored and may be null. Pass 2 must
61// replay the same chunk stream: a chunk whose count or descriptor differs from
62// pass 1 is refused. Nothing is spilled.
63// - SINGLE_PASS: one walk. Gaussians go to the output, high-order SH to a scratch
64// sibling that finalize() copies behind them and then deletes.
65//
66// A pass ends when it has received exactly `spec.chunk_count` chunks; the writer
67// then advances on its own. Declared means exact (W4): a chunk beyond the
68// declared count, a splat beyond `spec.splat_count`, a pass that ends short of
69// `splat_count`, or finalize() before every pass has completed all fail with a
70// "count_mismatch" message, and nothing is written to the final path.
71//
72// Invariants kept here (§4.4): W1 (nothing at the final path before finalize()
73// returns OK; on any failure, abort() or the destructor the temp and scratch are
74// removed and a pre-existing final file stays byte-intact), W2 (writes only grow
75// the file, apart from the final header rewrite), W3, W4, W5 (RAM is the chunk
76// table plus one 1 MiB slice; index lists are generated, never held), W6
77// (structural validity at append time, with the plain loader's rules), W7
78// (output bytes are a pure function of the spec and the appended stream), W9 (via
79// GSAtomicFileTransaction) and the structural part of W11 (begin_plain refuses a
80// spec the plain loader would refuse).
81//
82// Reader suspension (#714). On Windows an open reader denies the delete access
83// the atomic replace needs, and a world that is being streamed keeps pooled read
84// handles to exactly this file. finalize() therefore flushes first and then holds
85// StagedFileChunkPayloadSource::ScopedReaderSuspend on the destination across the
86// replace only. If in-flight reads do not drain within its bounded wait, the
87// replace is not attempted: finalize() returns ERR_BUSY, removes the temp and
88// leaves the destination as it was. (On POSIX the guard is a no-op: rename()
89// replaces a file readers still hold open.)
90//
91// Not thread-safe: one writer is driven by one thread. Only request_cancel() and
92// get_progress() may be called from another thread.

142// §4.3 Limits (BV-03b). Every field is required: a field left at 0 makes begin_plain()
143// refuse with "limits_unset", so no caller writes without stating its bounds. kUnbounded
144// is an explicit "no cap" (for the deadline: no deadline).
145//
146// Preflight. begin_plain() checks the limits and the free disk space BEFORE it creates
147// any file (the first byte), and refuses with a reason code:
148// limit_ram the per-world state it will hold (chunk table, chunk counts, metadata,
149// one 1 MiB slice) exceeds max_ram_bytes;
150// limit_scratch the SINGLE_PASS SH scratch exceeds max_scratch_bytes;
151// limit_output the file it will write exceeds max_output_bytes (codec none: exact);
152// preflight_disk the free space of the destination's directory is unknown (0), or is
153// smaller than output + scratch + min_free_disk_margin. With GSQ v1 the
154// output size is unknown at begin: the need is the smaller of
155// max_output_bytes and the uncompressed plain v3 size of the same world.
156// That size is an ESTIMATE, not a bound (page alignment and many small
157// pages can exceed it); the enforced bound is max_output_bytes, so a GSQ
158// caller that needs a disk guarantee sets it (follow-up: #1379).
159// While writing, every slice (<= 1 MiB) re-checks the output and scratch caps (GSQ
160// output is only known as it grows), the RAM cap after each chunk (GSQ page table and
161// the chunk's pages), the deadline ("deadline", ERR_TIMEOUT, wall time since
162// begin_plain()) and the cancel flag ("cancelled", ERR_SKIP). Any refusal goes through
163// the normal failure path, so W1 holds: temp and scratch are removed, nothing appears at
164// the final path, and a pre-existing final file stays byte-intact.
165constexpr uint64_t kDefaultFreeDiskMargin = uint64_t(64) << 20u;
